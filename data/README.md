# Данные ДЗ №2

## Состав и происхождение

- `raw/tools.csv` - 18 реальных open-source проектов; `source_url` указывает на официальный проект или документацию. `description_ru` и `description_en` - краткие авторские описания назначения и возможностей, а не автоматически выгруженные оригинальные README. Записи подготовлены вручную по публичным описаниям; версии исходных документов не зафиксированы. Текущие карточки подходят для пилотного EDA, но не для аудита версий документации.
- `raw/query_scenarios.csv` - 17 типовых инженерных сценариев по три естественные формулировки. Для каждого сценария указаны прямые (`relevance_2`) и частичные (`relevance_1`) соответствия возможностям инструментов.
- `processed/queries.csv` - 51 запрос, `family_id` и зафиксированный `split`. Разделение по семейству, не по отдельным перефразировкам.
- `processed/relevance_labels.csv` - полная таблица из 918 пар со степенями 0/1/2. Положительные метки соответствуют функциям инструментов, указанным в таблице сценариев. Метка 0 означает, что инструмент не включён в список соответствий сценарию; эта часть разметки формируется автоматически. Перед окончательной оценкой качества спорные соответствия следует перепроверить.

Открытый корпус не содержит персональных, внутренних или закрытых сведений. Ссылки ведут к публичным материалам разных правообладателей: при дальнейшем расширении корпуса нужно сверять лицензии и условия использования текстов. Здесь полные README и большие дословные цитаты не копировались.

## Закрытая часть корпуса

Дополнительно подготовлена разметка для 5 инструментов с ограниченным доступом.
Она не публикуется и не входит в показатели 18 инструментов / 51 запрос / 918 пар.
При наличии разрешения эти инструменты могут использоваться для отдельных
экспериментов по обучению в закрытом контуре. Для публичных результатов
сохраняется независимый, полностью воспроизводимый эксперимент на открытых данных.

## Воспроизведение

Из корня репозитория:

```bash
uv run --locked python scripts/build_dataset.py
uv run --locked --with-requirements requirements-eda.txt python scripts/eda.py
```

Скрипт сборки использует только стандартную библиотеку Python. Скрипт EDA создаёт шесть PNG-графиков. Результаты и исходные CSV уже добавлены в Git; интернет при пересборке датасета не требуется. Для ноутбука `notebooks/01_eda.ipynb` нужны зависимости из `requirements-eda.txt` и Jupyter/IPython.
