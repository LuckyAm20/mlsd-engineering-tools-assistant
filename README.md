# Engineering Tools Discovery Assistant

**Тема MLSD:** Проектирование интеллектуальной системы поиска и рекомендаций инженерных инструментов на основе RAG.

## Проблема

Инженерные утилиты описаны в разных каталогах, README и документах. Чтобы найти подходящий инструмент, приходится искать по ключевым словам вручную, сравнивать материалы и уточнять детали. Это затрудняет повторное использование готовых решений.

## Цель и сценарий

Ассистент должен принимать описание инженерной задачи на естественном языке, находить подходящие **доступные пользователю** инструменты и возвращать рекомендации с объяснениями, ограничениями и ссылками на подтверждающие источники. Если достоверных сведений недостаточно, система не должна придумывать ответ.

**Пример:** «Нужно собрать диагностические логи после обновления» -> список подходящих инструментов, причины выбора и ссылки на их документацию.

## Предлагаемое решение

1. Подготовка базы знаний из разрешённых описаний инструментов и документации.
2. Базовый лексический поиск (BM25); затем проверка, улучшает ли качество семантический поиск / обучаемое ранжирование.
3. Формирование ответа LLM **только на основе найденных источников** (RAG), с возможностью отказа от неподтверждённой рекомендации.
4. Оценка retrieval-качества и пользовательской полезности относительно простого поиска.

## Локальный запуск

Зависимости управляются через **uv**. `pyproject.toml` описывает проект и dev-зависимости.

1. Установите [uv](https://docs.astral.sh/uv/getting-started/installation/). Проверьте `uv --version`.
2. Из корня репозитория установите указанную версию Python и зависимости:
```bash
uv python install 3.11
uv lock                # первый раз или после изменения pyproject.toml
uv sync --locked
```
3. Запустите проверки:
```bash
uv run --locked poe hooks-install  # один раз: подключить хуки к git commit
uv run --locked poe check          # Ruff lint + format-check + pre-commit
```

**Дополнительные Poe-задачи:**
```bash
uv run --locked poe lint          # только линтер
uv run --locked poe lint-fix      # автоматически исправить часть замечаний
uv run --locked poe format        # применить форматирование Ruff
uv run --locked poe format-check  # убедиться, что форматирование не требуется
uv run --locked poe hooks         # вручную запустить все pre-commit hooks
```

После автоматического исправления файлов повторите `uv run --locked poe check` и добавьте изменения в Git.
